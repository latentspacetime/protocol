# People Research

Define the target relationship before searching: direct manager, functional
leader, recruiter, project owner, paper author, or another decision-maker.

## Research Standard

- Prefer official team pages, publications, conference biographies, repository
  ownership, and current public profiles.
- Use exact quotations and URLs for claims about title, team, or ownership.
- Confirm evidence is current; distinguish present roles from historical ones.
- Never infer identity from protected characteristics or private data.
- Do not use personal contact details that were not intentionally published for
  professional communication.

## Output

Return candidates by confidence tier. For each candidate, state the claimed
relationship, evidence, date, and uncertainty. Include ruled-out candidates
when they are likely to be confused with the target. If the exact person cannot
be established, return the best public organizational contact path instead of
guessing.
